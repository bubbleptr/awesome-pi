# Pi 对谈

入口为 `/talks/` 和 `/zh/talks/`，每期使用独立、固定的 slug。首页和指南页导航都提供入口。站点仍为 Astro 静态站，视频通过原始 `video.twimg.com` 地址播放；构建和浏览页面不调用模型 API。

## 内容

五期来源均为用户提供的 @pidotdev 原帖，2026-10-05 通过原帖元数据核对日期、时长、视频地址与主题。9 月 6 日一期是原帖标明的 Syntax.fm 访谈剪辑，9 月 20 日一期主要由 Armin 发言。

- `site/src/data/talks/*.json`：来源、播放地址、日期、实际时长、英文时间戳字幕、中英文总结。
- `site/public/talks/*.jpg`：从原视频第 3 秒提取的封面。
- 英文字幕由本机 Whisper large-v3-turbo 转写，可能包含口音、专有名词识别错误。总结根据转写整理，附原视频时间戳；它们不是逐字翻译或作者本人撰写的摘要。
- 原始音频及模型缓存在临时目录，不进入 Git。页面注明视频来源和 AI 内容属性。

新增一期时，在数据目录添加相同结构的 JSON 和对应封面；`/talks/[slug].vtt` 在构建时由字幕数据自动生成。总结条目包含 `start`、`title` 和 `text`。发布前确认字幕时间单调、未超出时长、总结能由对应片段支持，并运行 `bun run --cwd site validate`。

## 观看交互

原生播放器支持全屏、音量、进度和对应页面语言的 CC 字幕。下方全文可滚动、逐句点击定位；当前句按起止时间高亮，空隙不高亮。跟随播放只滚动字幕容器，不移动整个页面。滚轮、触屏和键盘滚动会取消跟随，可用“跟随播放”复选框恢复。时间戳跳转保留暂停状态。

点击字幕或总结时间戳会更新 `?t=秒数`，复制当前网址即可分享片段；打开链接后在视频元数据加载完成时定位，不自动播放。视频加载失败时提供直接视频和原帖链接。中英文字幕均可在对应语言页面下载为 WebVTT。

桌面端视频与滚动字幕并排显示，字幕区高度随左侧播放器区域对齐；AI 总结独立放在下方。窄屏把滚动字幕放在视频下方的紧凑面板内。播放器默认显示由页面绘制的字幕层（中文页中文，英文页英文），使用直角黑底和 700 字重；右上角提供字幕开关和容器全屏按钮。原生 WebVTT 保留作为无 JavaScript、系统原生全屏的回退，系统原生全屏的样式由平台决定。当前句绿色高亮，自动跟随平滑滚动，减少动态效果设置下直接定位。默认只加载视频元数据，不预下载整段视频。所有正文在静态 HTML 中，原生播放和字幕下载不依赖 JavaScript。

已有 Whisper JSON 时，可运行 `bun site/scripts/import-talk-transcript.ts <slug> <whisper-json>` 导入。导入器会限制结尾到实际视频时长、消除相邻时间重叠，并对无效时间与空文本报错。原有总结不自动改写，应在更新字幕后重新核对。

## YouTube 播放

`changing-models` 与 `pi-durable` 两期已由 @pidotdev 官方上传至 YouTube 且允许嵌入，这两期改用 YouTube 嵌入播放器，不再依赖 twimg 防盗链放行；其余三期仍走 twimg `<video>` 直链。数据层在对应 JSON 增加 `youtube` 字段（11 位视频 ID），`video` 字段保留用于开发代理校验。新增官方上传的一期时只需在其 JSON 写入 `youtube`。

嵌入 iframe 显式声明 `referrerpolicy="strict-origin-when-cross-origin"`：页面为 twimg 设置了 `no-referrer`，而 YouTube 嵌入无 Referer 会拒绝播放（Error 153），iframe 上的策略覆盖页面默认值，只发送源站。播放器通过 IFrame API 接入 `MediaClock` 抽象，与 `<video>` 共用同一套转写交互。时间点跳转在播放器未开始播放时调用 `cueVideoById` 定位以保持暂停状态（`seekTo` 会自动开始播放）；已开始播放后仍用 `seekTo`。时间戳沿用既有转写数据，两期官方上传时长与数据时长相差 0.5 秒以内，未单独回听核对音频对齐。

YouTube 期不渲染自定义全屏按钮，全屏用 YouTube 自带按钮（此时不显示网站字幕层）；字幕开关移到视频下方 `.talk-source` 行内，避免遮挡 YouTube 顶部控制区。播放器首次进入播放状态时调用 `unloadModule('captions')` 关闭 YouTube 自带 CC（用户仍可用其 CC 按钮重新打开），避免与网站字幕层重复。字幕条仅在 YouTube 控制栏可能显示时——暂停或未播放状态——通过 `data-controls` 上移避开进度条与控制栏；跨域 iframe 不会向父页面派发指针边界事件，悬停检测无法实现，故播放中悬停时字幕条保持低位。twimg 期的视频内控件不变。

## 开发环境视频播放

开发页面使用 `/__talk-media/<slug>.mp4` 同源地址，由 Vite 转发到该期原始 MP4。代理仅匹配五期数据中的固定路径，保留 Range 请求与 206 响应，支持跳转；不向视频 CDN 转发浏览器 Cookie、Authorization、Origin 或 Referer。无需下载整段视频或把视频加入 Git。生产静态构建仍使用原始 CDN URL；这个代理只在 `bun run dev` 时运行。

修复原因：开发浏览器直连 `video.twimg.com` 实际收到 403（文本响应），而服务端获取相同地址得到 206 MP4。同一文件从开发服务器加载时能正常解码播放。单纯检测 `canPlayType` 或 URL 可下载不能证明浏览器能播放。`<source>` 的 `error` 不冒泡，因此播放器也监听它的失败事件。

真实浏览器回归脚本为 `site/scripts/check-talk-playback.mjs`。在 Ego 中建立或复用任务空间后，将 `globalThis.PI_TALKS_TASK_SPACE = 空间编号;` 前置到脚本，通过 `ego-browser nodejs` 执行。它逐期检查实际播放时间前进、视频帧解码、总结时间戳跳转、字幕高亮与容器滚动；单元测试之外还需要这项验证。

2026-10-05 修复验证：五期均在真实浏览器中开始播放并解码出画面，跳到总结中段后继续播放，当前字幕与播放时间匹配，字幕容器 `scrollTop` 增加。61 项数据／交互测试、34 项构建页面测试与 Astro 类型检查通过。较长视频首次加载可能超过 12 秒，浏览器回归为网络加载保留 30 秒上限。

2026-10-06 字幕可读性调整：保留“滚动字幕 EN”标题与原有跟随播放复选框，仅移除标题下的小字说明。对长段使用原音频和 Whisper 的词级对齐拆分，保留转写全文，优先在句末或停顿处换行；发布检查限制单条最长 8 秒。侧栏与视频内 WebVTT 使用同一份分段数据。
